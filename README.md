# 🚀 AOV Account Filter - Công Cụ Lọc Tài Khoản Nâng Cao

Công cụ web tĩnh (chạy hoàn toàn trên trình duyệt) giúp bạn lọc, phân loại và quản lý danh sách tài khoản Liên Quân Mobile (AOV) nhanh chóng dựa trên các chỉ số, bộ sưu tập skin và trạng thái bảo mật.

## ✨ Tính Năng Nổi Bật

- **Nhập liệu linh hoạt**: Hỗ trợ dán trực tiếp danh sách tài khoản vào khung văn bản hoặc tải lên file `.txt`.
- **Lọc thông số nâng cao (`≥`)**:
  - Chỉ số: Tướng, Skin, Level, Quân Huy.
  - Bộ sưu tập: SS, SSS, Anime, Other.
- **Lọc theo từ khóa/Skin**: Tìm kiếm chính xác tên skin yêu cầu (hỗ trợ nhập nhiều skin cách nhau bằng dấu phẩy) hoặc tên nhân vật (`NAME`).
- **Lọc trạng thái & Bảo mật**: Trạng thái `BAN`, `SĐT`, `Email`, `Authen`.
- **Tùy chọn xử lý trùng lặp**: Bỏ trùng dòng y hệt, bỏ trùng theo username hoặc chuẩn hóa khoảng trắng/case.
- **Xuất file nhanh chóng**: Tải xuống kết quả lọc ngay về máy chỉ với 1 cú click.

## 🛠️ Hướng Dẫn Đưa Lên GitHub Pages

Để sử dụng công cụ này làm một trang web online cá nhân trên GitHub, bạn thực hiện các bước sau:

1. **Tạo Repository mới trên GitHub**:
   - Truy cập [GitHub](https://github.com) và tạo một repository mới (đặt tên tùy ý, ví dụ: `aov-filter`).
   - Để chế độ **Public**.

2. **Tạo file `index.html`**:
   - Tại giao diện repository, bấm **Add file** -> **Create new file**.
   - Đặt tên file là `index.html`.
   - Copy toàn bộ mã nguồn của trang web dán vào nội dung file.
   - Bấm **Commit changes** để lưu lại.

3. **Cấu hình GitHub Pages**:
   - Chuyển sang tab **Settings** ở thanh menu trên cùng của repository.
   - Ở cột bên trái, tìm và chọn mục **Pages** (dưới phần *Code and automation*).
   - Tại mục **Build and deployment** -> **Branch**:
     - Chọn nhánh là `main` (hoặc `master`).
     - Chọn thư mục là `/ (root)`.
     - Bấm **Save**.

4. **Trải nghiệm**:
   - Đợi khoảng 1-2 phút, GitHub sẽ cập nhật và hiển thị đường link trang web của bạn ngay tại đầu trang **Pages**. Bấm vào link đó để sử dụng mọi lúc mọi nơi!
